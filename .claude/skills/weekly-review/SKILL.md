# 週次レビュー

週末に1回実行する。以下を順に行う：

1. **誤答集計**：`mistakes.md` を読み、分野別（Monitoring / Reliability / Deployment / Networking / Security）に件数と頻出タグを集計する
2. **進捗更新**：`progress.md` を更新する
   - 週次チェックリストのチェック
   - 模試スコア記録（ユーザーに今週のスコアを確認）
   - 分野別の到達状況（☆〜★★★★）
   - 週次レトロスペクティブ（やったこと / 学び / 持ち越し）
3. **CLAUDE.md の「現在の学習フォーカス」を書き換える**
   - 現在の週、今週のテーマ（docs/guidelines/app-roadmap.md の週別表に従う）
   - 直近の弱点（手順1の集計結果から上位2〜3論点）
   - アプリの現在の状態
4. **来週の優先順位**：残り日数と未達分野から、1日1時間×7日の配分案を提示する

## ルール

- 残り期間の計算は「Week 8 末に受験」を基準にする
- 弱点分野は出題比率（22/22/22/18/16%）で重み付けして優先順位を決める
